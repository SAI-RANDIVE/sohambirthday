# Sohamverse Asset Folder

Place your personal media here.

Suggested structure:

- images/ for portraits and milestones
- videos/ for birthday / family / friends clips
- audio/ for intro, countdown, game, and final music

Use descriptive filenames such as:

- SohamBaby.jpg
- SohamSchool.jpg
- SohamBestPhoto.jpg
- SohamVideoChildhood.mp4
- birthday_music.mp3

The site is designed to skip missing files gracefully, so you can add assets gradually.
